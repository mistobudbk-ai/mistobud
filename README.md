# БК Містобуд - Сайт будівельної компанії

Сучасний мінімалістичний веб-сайт для будівельної компанії БК Містобуд.

## Стек технологій

- **React 18** - UI бібліотека
- **TypeScript** - Типізація
- **Vite** - Швидкий збирач
- **Tailwind CSS** - Утиліти для стилізації
- **React Router** - Навігація
- **Lucide React** - Іконки

## Установка

```bash
# Встановити залежності
npm install

# Запустити dev сервер
npm run dev

# Збудувати для продакшену
npm run build

# Переглянути білд
npm run preview
```

## Структура проекту

```
src/
├── pages/          # Сторінки
│   ├── Home.tsx
│   ├── About.tsx
│   ├── Services.tsx
│   ├── Portfolio.tsx
│   └── Contact.tsx
├── components/     # Компоненти
│   ├── Header.tsx
│   └── Footer.tsx
├── App.tsx         # Головний компонент
├── main.tsx        # Точка входу
└── index.css       # Стилі
```

## Сторінки

- **Головна** - Привабливий герой, послуги, переваги, CTA
- **Про нас** - Історія, цінності, команда
- **Послуги** - Детальний список всіх послуг
- **Портфоліо** - Галерея проектів з фільтрацією
- **Контакти** - Форма зв'язку, карта, координати
